# Riftbound cosmos and weather provenance

Prepared 2026-09-13 for version 0.9. Assets are generated by
`Scripts/bootstrap_voyager_cosmos.py` through the installed Unreal Engine 5.8.2 editor.
The pipeline writes project materials under `Content/Cosmos` and a local verification
report under `Saved/VoyagerCosmosMaterialsReport.json`. It performs no external download.

## Original project work

`M_CosmosHorizon`, `M_CosmosDisk`, `M_CosmosLimb`, `M_CosmosCloudDistant`,
`M_CosmosOcean` and `M_CosmosDust` are project-authored material graphs and shader code.
`VoyagerCosmos.cpp` creates the seeded anomaly geometry, disk and apparent halo.
These implement a visual approximation and bounded gameplay hazard, not a
general-relativistic ray tracer or an astrophysical gravity simulation.

## Installed Unreal Engine weather

`MI_CosmosWeather` is a project material instance whose hard parent reference is:

`/Engine/EngineSky/VolumetricClouds/m_SimpleVolumetricCloud_Inst.m_SimpleVolumetricCloud_Inst`

That parent and its dependent shader functions/textures come from the user's installed
Unreal Engine. They are Epic engine content, not original Riftbound shader work. The
repository contains the project instance and its parameter choices; it does not copy the
engine parent assets into the source tree. Unreal's cooker follows the hard parent reference
when producing the game. Building the project requires the compatible engine installation.

The native `SkyAtmosphere` and `VolumetricCloud` components supply atmosphere and volume
rendering. Runtime planetary radius, center, coverage and cloud scale are configured by
`VoyagerWorld.cpp`; the distant orbital cloud pattern is separately authored by this project.

No paid Fab, marketplace or other third-party planet, atmosphere or black-hole pack was
acquired for this pass. Existing character, nature, audio and ship credits retain their
separate provenance documents. Do not describe the native weather parent as CC0 or as
project-owned artwork.
